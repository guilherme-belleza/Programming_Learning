# 💻 Terminal e Sistemas

Materiais de estudo relacionados ao uso do terminal, sistemas operacionais e ferramentas utilizadas durante o aprendizado de programação.

## 📚 Estrutura

### Windows

* `01_cmd_windows.md` — comandos básicos do Prompt de Comando do Windows
* `02_powershell.md` — comandos e recursos básicos do PowerShell

### Linux

* `03_linux.md` — fundamentos do Linux, estrutura de diretórios, navegação, permissões, processos, pacotes, rede e armazenamento
* `04_linux_2.md` — comandos e conceitos Linux voltados para desenvolvimento, automação, processos, SSH e gerenciamento de serviços

### Segurança

* `05_kali_linux.md` — estudos introdutórios sobre Kali Linux e ferramentas relacionadas à segurança

## 🎯 Organização

Os materiais foram organizados de acordo com o sistema ou área principal de estudo.

O objetivo desta organização é facilitar a **consulta, revisão e evolução do aprendizado** sobre terminal, sistemas operacionais e ferramentas utilizadas no desenvolvimento.

---

> 📌 **Este material está em constante evolução conforme avanço nos estudos de programação, Linux e segurança.**
